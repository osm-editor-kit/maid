# Browser checks

Each check drives an app with real input and compares data and map after each step. `bun run check-all` runs them one after another (list and expected `ok` lines in `check-all.ts`).

The browser checks need `bun run dev` and take `[scene]` and `--app maid|bicycle|parking|indoor` (read in `tools/bench/args.ts`):

| Check                   | What it does, with real input, comparing data and map after each step                                                                                                                                                                                                                                                |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `check-interactions`    | iD's behaviour: Shift-click, dragging nodes and points, double click, drawing keys, move, rotate, copy and paste                                                                                                                                                                                                     |
| `check-edit`            | Add, change and delete a point, delete a way, undo and redo                                                                                                                                                                                                                                                          |
| `check-draw`            | Draw a line, continue it, snap to a node and a way, draw an area, cancel                                                                                                                                                                                                                                             |
| `check-undo`            | Move a vertex, change a tag, undo and redo                                                                                                                                                                                                                                                                           |
| `check-ops`             | Square a building, split a road, merge the parts, undo                                                                                                                                                                                                                                                               |
| `check-relations`       | Add a way to a relation, change its role, remove it, undo; a multipolygon follows its moved node. `check-all` runs it on `small` and on `relations` (routes, turn restrictions, boundaries)                                                                                                                          |
| `check-relation-column` | Scene `relations`: "Open" on a bus route shows its members beside the inspector and keeps the road selected; a member row selects it, the head selects the relation, a click on a row also moves the map to it (no "Fly to" buttons), "Add it" for a feature that is not a member (one undo step), closing with the head's button, "Open" in the Members section and Escape |
| `check-route-overview`  | Scene `relations`: the route overview in the relation column. A bus route's stops in order and no junctions, the Schematic and To scale toggle, hover from a row to the map and from the map to the row, a click selects and keeps the column's scroll, an (i) note opens, closes with Escape and gives the focus back, the fold button; a hiking route starts with no note open, its junctions without a guidepost folded into a row that lights on hover, opens, has one (i) note that it is no error and folds again from the note, its group of members that are not loaded; a route master's variants as groups with their lines, the handle opens the order view (all folded), "down" swaps two variants, one undo, "Done"; the preview from the mock's Postpass fixtures: "Load preview" above and below, one request per press, "Preview from" and reload, muted rows, the lines on the map, the stored preview after a page reload with no request and on the map without a hover, a click on a preview row loads the real member |
| `check-validation`      | A footway that crosses a road and connects to nothing: both reported, fix, undo                                                                                                                                                                                                                                      |
| `check-close-nodes`     | A building with two points 3 cm apart: the issue, the amber ring on the map, Square merges them, undo                                                                                                                                                                                                                |
| `check-journal`         | Edit, reload, restore from the browser's storage, undo all, reload, discard                                                                                                                                                                                                                                          |
| `check-filters`         | Hide buildings, make them read-only (faint, a click passes them), reset, a filter in the URL                                                                                                                                                                                                                                                 |
| `check-tags`            | The tags sheet on a bare page: typing, moving, renaming, pasting and copying `key=value` lines, shortcuts stay out of a cell                                                                                                                                                                                         |
| `check-multi`           | Two buildings selected: "Multiple values", one undo step for both, a new tag for both, refusal when read-only                                                                                                                                                                                                        |
| `check-lanes`           | `--app lanes` only: the section "Lanes" with its diagram, a value per lane (one key, one undo step), a lane added and removed, the cycle lane pattern, a lane chosen in the diagram, the lane bands and arrows on the map, a lane rule in the Issues dock with its fix |
| `check-parking`         | `--app parking` only: quick buttons on one and two roads, restriction field, a parking rule, "Copy parking to the other side", the parking lens                                                                                                                                                                      |
| `check-way-table`       | `--app bicycle`, scene `relations`: the columns and "Different" cells, "Show more", a cell edit and "Set on N", each one undo step; "Highlight changes" (before → after, a removed tag as a row)                                                                                                                                                                                   |
| `check-reroute`         | `--app bicycle`, scene `relations`: start a reroute, two clicks, the preview and its length, Apply, one undo, Escape ends the mode; the edit menu's "Reroute the route" on a way, its flyout, a handle and the line dragged, Apply, one undo                                                                                                                                                                                   |
| `check-sidepaths`       | `--app bicycle`, scene `medium`: "Tags to … sidewalk" on Bebelplatz (one side moves, the other keeps its surface, which its sidewalk has otherwise), the edit menu entries, undo; Alexanderstraße's lane key is nothing to move. Screenshot in `reports/sidepaths-menu.png` |
| `check-bike-style`      | `--app bicycle`, scene `bicycle`: the default look of the bicycle editor (module-bike-infrastructure): every made-up case is drawn with its TILDA category (paths on the way, road sides beside the road, separately mapped sides dotted), the traffic signs get their images, the report's sidewalk is "Sidewalk, bicycles allowed", the lens `surface` hides the lines, `bike-infrastructure` and `none` show them. Screenshots in `reports/bike-style/`. `MAID_MOCK_PORT=<port>` sends the mock requests to another mock (one started after the scene was added) |
| `check-rectangle`       | `--app parking|indoor`: 3 then 3 again (33) and the Area dropdown draw a rectangle with three clicks: right angles, also on a turned map, one undo step, Escape leaves nothing, a corner on an existing node reuses it                                                                                                      |
| `check-room`            | `--app indoor`: the Room button is off without a building and on with one; a click on a wall, two corners with Shift and a click on another wall make an `indoor=room` that shares its wall nodes with the building, one undo step; Escape writes nothing; on level 0 Enter ends the room along the guide and it gets `level=0`. `ROOM_SHOTS=<dir>` saves screenshots |
| `check-angle-snap`      | `--app parking|indoor`: Shift while drawing gives 45° steps and a square area, Shift while dragging a corner keeps it square, guide lines, key press without a move, window blur, a turned map                                                                                                                              |
| `check-merge`           | `--app parking|indoor`: two overlapping areas merged with C into one outline, one undo step; different tags refuse with a reason; a line and an area are not offered                                                                                                                                                        |
| `check-cut`             | `--app parking|indoor`: "Cut" in the edit menu shows a cut line across the long side with handles and a preview of the two pieces; dragging a handle or the midpoint (a new corner), a click moves the nearer end, Enter gives two areas with the tags, one undo step; a line that does not cross is refused                |
| `check-divide`          | `--app parking|indoor`: "Divide" in the edit menu, columns and rows with the keys, the preview, Enter gives the parts with shared nodes, all selected, one undo step                                                                                                                                                        |
| `check-extrude`         | `--app parking`: "Extrude" (J, tooltip with Shift) puts a handle on each side of an area; the east side pulled out makes the rectangle longer with no new corner and the panel shows the distance; two clicks on the outline add two corners, the part between pulled out is a bump with two new corners; Shift moves the bump's side without new corners; one undo step each, the mode stays on; Enter, undo, Escape |
| `check-resize`          | `--app parking|indoor`: "Resize" (K) puts a box with eight handles on an area; an edge stretches one side and keeps the grab point, Shift on a corner keeps the proportions, Alt the centre, a key pressed mid-drag counts at once, the panel toggle; the data stays while dragging, Enter makes one step, Escape, undo only ends it, a click outside |
| `check-display`         | W turns the wireframe on and off, G highlights what was changed (added, moved, retagged), `display=` in the URL, a reload keeps it                                                                                                                                                                                   |
| `check-touch`           | `--app parking|indoor`, touch input: a long press on the Area button opens its dropdown, a long press on a feature opens the edit menu, a long press while drawing works as Shift (45°)                                                                                                                                     |
| `check-menu`            | The edit menu: "Continue" first on the end of a line (and the A key), no "Paste" on a feature, only "Paste" on open ground, "Delete segment" on a line (the segment marked in blue on hover, one undo step), "Treat as area" on a closed untagged line                                                                                                                                              |
| `check-merge-polygon`   | An outer and an inner area merged with C into a multipolygon, as iD: roles, tags on the relation, one undo step                                                                                                                                                                                                      |
| `check-favourites`      | The star in the type search, the number badge, the favourites panel in the top bar: number, remove, start drawing from it                                                                                                                                                                                            |
| `check-move-handle` | The move handle on a phone (`?device=touch-ios`), with real touch input: a building and a road get it, a drag moves the whole feature by the finger's way without panning, keeps it selected, is one undo step |
| `check-rotate-handle` | Rotating on a phone (`?device=touch-ios`), with real touch input on a building: the menu button beside the move handle opens the edit menu, its Rotate shows the rotate handle and the panel, a drag of the handle and a two-finger turn turn the building and neither the map; Done is one undo step, Cancel takes it back, a tap on the map ends it |
| `check-tooltips`        | The tooltips of the top bar and the tool groups: the delay, switching at once between neighbours, the key shown                                                                                                                                                                                                      |
| `check-levels`          | `--app indoor`, scene `indoor`: `level=` in a link, the floor picker lists the floors in view and chooses one, a room on another level is dimmed and cannot be selected or changed, new features get the level, "All" ends it, "3D" tilts the map and extrudes the rooms                                      |
| `check-osmchange`       | `--app bicycle`: "Load changes from a file…" with an osmChange file made from older versions (the mock's hand-written history): the review's groups, a tag decision, a delete that starts on "keep", Apply as one undo step, the data afterwards, one undo, a file refused over unsaved changes |
| `check-tasks`           | A task list from `?tasks=`: the cleanup dialog for a list of 40 days, the dock tab, a row selects its way, the task in the inspector, an option's diff and Apply (one undo step), Ignore, the progress in the mock's user preferences (no key over 255 characters, no PUT of all), a reload restores it, 20 000 tasks into `reports/tasks-perf.json` |
