# Mapterhorn elevation sources: OSM licence compatibility

Date: 2026-11-12. Repository: `mapterhorn/mapterhorn` (shallow clone at `a local clone`, HEAD `2c4195d` "Fix typos (#363)"). mapterhorn.com was not reachable. The OSM wiki and the OSMF waiver pages were not fetched, so every OSM classification below is inferred from my own assumption (not checked) and general knowledge.

## Found (measured in the repo)

- 153 source folders in `source-catalog/` (`source-catalog/README.md` lists the layout). Each has `metadata.json` (`name`, `producer`, `producer_short`, `license`, `website`, `resolution`, `access_year`) and `LICENSE.pdf`.
- All 153 `LICENSE.pdf` files yield text with `pdftotext`. A keyword scan for non-commercial, no-derivatives, share-alike, OpenStreetMap, ODbL and waiver found no licence that forbids commercial use, derivatives or share-alike. Every "non-commercial" hit is a permission for commercial use (for example DL-DE Zero 2.0, Estonia, the French IGN licence, the Slovenian ARSO licence). The `no` class is therefore empty. This matches `CONTRIBUTING.md`, which says share-alike and non-commercial licences are not accepted.
- The attribution page (`website/attribution/index.html`) is built from `https://download.mapterhorn.com/attribution.json`. That file is generated by `pipelines/attribution.py`, which is not the same as the folder metadata. It takes `name`, `website`, `license`, `producer`, `producer_short`, `resolution` and `access_year` from each `metadata.json`, so the licence text on the page is the repo text.
- `CHANGELOG.md` line 197 says the aggregation started with Copernicus GLO-30 (30 m, global) and swissALTI3D. GLO-30 is therefore the base layer.
- `source-catalog/debug-glo30` and `source-catalog/debug-swissalti3d` duplicate `glo30` and `swissalti3d` (same licence and producer). They are counted in the 153 rows.

## Key findings

1. **Copernicus GLO-30 (`glo30`) is unclear, and it is the global base.** The licence (`glo30/LICENSE.pdf`) is a custom EU licence. It is free of charge and worldwide, with no time limit (Art. 3 to 5). It allows reproduction, distribution, communication and adaptation (Art. 4). Art. 6 requires the notice "© DLR e.V. 2010-2014 and © Airbus Defence and Space GmbH 2014-2018 provided under COPERNICUS by the European Union and ESA; all rights reserved", and adapted data must carry "produced using Copernicus WorldDEM-30 …". Art. 9 says the provider keeps the IPR. This is not a standard open licence, and I know of no OSMF statement on it. If the editor warns on GLO-30 alone, it will warn almost everywhere.
2. **The Japanese GSI approval has probably expired (`jpdem*/LICENSE.pdf`).** The PDF is an approval letter (測量法 第30条) for "地図データ「Mapterhorn」作成のため", dated 令和8年6月15日 (2026-06-15). The use period is "承認後３か月間" (3 months after approval), so it ended around 2026-09-15. The conditions are to print "測量法に基づく国土地理院長承認（使用）R 8JHs 131" and to send a copy or URL. The approval covers Mapterhorn only, not OSM. Check whether it was renewed.
3. **ASTER (`isr10`) is unclear.** The metadata and the PDF say "public domain", but the same PDF limits GDEM v2 to users in the GEOSS societal-benefit areas. Public domain applies to v3. The repo does not state which version the 10 m Israel DEM uses.
4. **Norway is not NLOD in this repo.** The Kartverket source (`no`) and Svalbard (`nosvalbard`) are CC BY 4.0 (the PDF confirms the CC BY 4.0 licence). They are unclear, not yes. The NLOD case in my own assumption (not checked) does not appear in the catalog.
5. **Switzerland.** `swissalti3d` uses the swisstopo OGD terms (`swissalti3d/LICENSE.pdf`). Commercial use is allowed and a source reference is mandatory. There is no OSM statement, so it is unclear. Zürich canton (`chzh`) is CC0 and is yes, but it is not in the Alps.
6. **Tiles are composites.** A tile can draw on several sources. The per-tile source list is in the coverage index (section "Tile endpoints"). An editor warning should use the sources at the clicked location, not a single label for the whole layer.

## Attribution

- Mapterhorn's own string is `© Mapterhorn`, linking to `https://mapterhorn.com/attribution`. It appears in `pipelines/utils.py:109`, `pipelines/bundle.py:182`, `pipelines/create_coverage_index.py:163` and the website examples. The attribution page says "Mapterhorn uses the following open-data sources to build its terrain tiles." The README says "Terrain data: various open-data sources, for a full list see https://mapterhorn.com/attribution."
- The per-source form in `website/examples/attribute-visible-sources/example.html` is `© {producer_short}`, linked to the source's `website`.
- Source-specific wording that the licence itself requires:
  - GSI Japan: "測量法に基づく国土地理院長承認（使用）R 8JHs 131".
  - Copernicus: the Art. 6 notice above.
  - swisstopo: "©swisstopo" or one of the listed source references.
  - Spain (IGN, `es*`): the licence form "<product> <date> CC-BY 4.0 <producer>".
  - DL-DE BY 2.0 sources: the "Datenlizenz Deutschland – Namensnennung – Version 2.0" notice with the producer (inferred from the licence text).

## Tile endpoints and encoding (stated in the repo)

- Raster tiles: `https://tiles.mapterhorn.com/{z}/{x}/{y}.webp`, encoding `terrarium`, `tileSize` 512 (`README.md` migration snippet; `website/viewer/index.html:110`, `pipelines/bundle.py:177`).
- TileJSON: `https://tiles.mapterhorn.com/tilejson.json` (`website/data-access/index.html:74`).
- PMTiles: `https://download.mapterhorn.com/planet.pmtiles` (zoom 0 to 12), plus area extracts (`website/data-access/index.html`).
- Coverage index: `https://download.mapterhorn.com/coverage-index.pmtiles`. It has one tile per zoom-12 macrotile. Each tile is JSON keyed by source id, with that source's metadata (`pipelines/create_coverage_index.py`, lines 142 to 145). `website/examples/attribute-visible-sources/example.html` reads it. Use this for per-location source warnings.
- Terrarium decoding: height = R × 256 + G + B / 256 − 32768 (standard for this encoding; inferred).
- None of these endpoints was reached from here. Nothing was measured live.

## Proposed notice text for the editor

The notice names the source at the clicked location, from the coverage index. Replace `{producer_short}`, `{licence}` and `{year}` from the source's metadata.

**Yes class (English):**
> Terrain: Mapterhorn, source {producer_short} ({licence}, accessed {year}). Attribution: © Mapterhorn; © {producer_short}. Full list: mapterhorn.com/attribution.

**Yes class (Deutsch):**
> Gelände: Mapterhorn, Quelle {producer_short} ({Lizenz}, Stand {year}). Quellenangabe: © Mapterhorn; © {producer_short}. Vollständige Liste: mapterhorn.com/attribution.

**Unclear class (English):**
> Terrain: Mapterhorn, source {producer_short} ({licence}). This licence is not known to be compatible with the ODbL. Do not use these heights to derive OSM data (tracing, contours, elevation tags) until the licence has been checked. Details: mapterhorn.com/attribution.

**Unclear class (Deutsch):**
> Gelände: Mapterhorn, Quelle {producer_short} ({Lizenz}). Für diese Lizenz ist nicht bekannt, dass sie mit der ODbL vereinbar ist. Höhen aus dieser Ebene nicht ohne Prüfung für OSM-Daten verwenden (Nachzeichnen, Höhenlinien, ele-Tags). Details: mapterhorn.com/attribution.
