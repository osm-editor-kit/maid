## What it is

A Go service with three parts:

- `betawatch-ingest` follows the OSM minute diffs (or imports a pre-filtered planet PBF) and keeps every climbing element in SQLite. Selected are `climbing`, `climbing:*`, `sport=*climbing`, `sport=*boulder`, `path=climbing_access`, `leisure=climbing`.
- `betawatch-feed` serves a live feed of changes, a map, stats and a **problems page**: named SQL rules from the config, each listing the elements it flags.
- A check of `wikimedia_commons` files against the Commons API (exists, size, type), once per file.

There is also a read-only MCP endpoint (`/assistant`) for an LLM to run SELECT queries on the database. Licence: AGPL-3.0. Maid takes ideas and the tag rules, not code.

Rules that are **off** in BetaWatch (too noisy or disputed), and Maid should leave them off too or keep them as hints: missing name; a route with several styles set to yes; `climbing:pitches` without `multipitch`; `climbing:orientation` format; `highway=*` on a route.

**Unwanted tags** (54 keys and values): misspellings and old forms such as `climbing:grade` without a system, `climbing:grade:fontainebleau`, `climbing:bouldering`, `climbing:traditional`, `climbing:style=sport`, `climbing_type`, `site=climbing_area`, `sport=rock_climbing`. Maid shows these as outdated tags; where the new key is clear (`climbing:traditional` to `climbing:trad`, `climbing:grade:fontainebleau` to `climbing:grade:fb`) it offers the change. The full list is in the config.

## Rules that BetaWatch cannot check, and Maid can

BetaWatch reads tags, one element at a time. Maid has the graph and the relations, so it adds the checks of the plan's step 4: a route in no crag, a crag point with routes nearby, a crag relation with members that are not routes, and the member order.

## Example places

The problems page would show real places with real errors, a good source for a test area and for a real fixture (plan step 9). It was not reachable here. A person can open the problems page, pick a crag with several problems and cut it from an extract (core rule 1: no automated requests, so neither Maid nor an agent reads BetaWatch).
