## 3. What "a built app that includes this" means for `apps/maid` (and `apps/maid-bicycle`)

Engineer's reading, not legal advice.

- **Texts and structure** are JavaScript and JSON inside the app's bundle. The package's GPL-3.0-or-later applies to them. If the app is conveyed (a served web app counts as conveying, as the usual reading goes, since the code is sent to the browser), the app that contains them is conveyed under GPL-3.0 terms as a whole. ISC code can sit inside a GPL-3.0 work, so this is possible; the consequence is that the app as built is GPL-3.0, not ISC.
- **Icons** are GPL-3.0-or-later per the package. Same consequence, for the icons only.
- **Photos** are not GPL. Each file keeps its own licence. The duties are attribution and the licence notice; for the CC BY-SA files, ShareAlike applies to adapted material, and an unmodified photo is not adapted [inferred]. The flyouts show credits (module README, "Photo credits"); whether every served photo has a complete credit is not checked, see the two gaps above.
- **`apps/maid-parking` is not affected**: it has none of the files and no import.
- Whether the app's source must be offered to users depends on the GPL terms for the conveyed app. The repository's visibility was not checked here. [unsure]

The icons are the real work. The texts need Tobias's view (above) to stand; without it, the texts stay under GPL too. Would leave the built apps ISC. |

Relicense the package's own parts | The package's authors license their own code (`dist/index.js` helpers, types, scripts) under a permissive licence, and declare the data's real licences per part. | Upstream change in the other repository (a person does it; see `docs/upstream/surface-smoothness-data-licence.md`); a LICENSE per part; a new published version. | Low for us, but it does not help on its own: the texts, the matrix and the icons come from StreetComplete (GPL-3.0), and only StreetComplete's contributors could relicense those.
